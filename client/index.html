How It Works

Trade, approve,
sign in layers.

01
ASA Bot decides

AI engine (Groq) analyzes market and sends a trade intent to the bridge server.

02
Policy checked on-chain

Anchor program verifies max buy, daily limit, and stop loss before any signature is requested.

03
Ika MPC signs

dWallet generates signature via 2PC-MPC - agent never holds the private key.

04
Trade executes

Signed transaction is broadcast to Solana. Policy counters update on-chain atomically.

Security Architecture

Built for
zero-trust agents.

No raw private key

Your .env never contains a private key. The dWallet keypair is split between you and Ika's MPC network. Neither party alone can sign.

Cryptographic policy

Rules aren't just Python code - they're enforced by a Solana Anchor program. Bypassing the policy means bypassing the blockchain.

Daily spend tracking

On-chain counters track daily spend atomically. Resets automatically. No way for a compromised agent to exceed limits.

Telegram override

Emergency pause, policy update, and trade history - all from your Telegram. Override the agent at any time without touching code.
